# 1. Record architecture decisions

Date: 2026-11-22

## Status

Accepted

## Context

The OccupySaaS umbrella gathers several independently maintained projects. Decisions that span more than one member need one durable home, or each repository grows a contradictory half of the same rule.

## Decision

Every cross-cutting decision is recorded as a numbered ADR in this directory.

## Consequences

A decision has one citable address. Members link to it rather than restating it.
